# Haven — PC 语音助手需求摘要

## 项目定位
基于 ReAct 架构的 Windows PC 语音助手。热键唤醒、语音输入、MCP/Skills/本地工具调用、UI+通知输出。

## 交互方式
- 唤醒：热键 Push-to-Talk（按住说话/按一下切换，两种模式）
- 输入：语音 → 本地转写 → 文本（音频不上传云端）
- 输出：UI 展示 + 系统通知（不语音播报）
- 运行：开机自启 + 系统托盘常驻

## 平台与技术栈
- **首发平台**：Windows，架构预留跨平台
- **后端**：Rust 统一后端，多 crate 拆分
- **前端**：Tauri + SvelteKit SPA
- **持久化**：SQLite
- **音频捕获**：CPAL
- **LLM**：云端优先，本地备选，多模型路由（namer / reasoner / fallback）
- **STT**：通过 MCP（优先，用户自配 STT 服务器）或自定义 LLM 完成，不内置引擎

## 核心能力

| 模块 | 能力 |
|---|---|
| 工具生态 | 外部 MCP（手动配置+自动发现）、本地 Skills（脚本/模板）、内置工具（文件/进程/剪贴板，截图后续版本内置） |
| 键鼠/窗口 | 通过 MCP 提供，不内置 |
| 并行与打断 | 多任务并行；新输入自动分类为「新任务」或「补充当前上下文」 |
| 安全 | 高危操作（删除/终止/写入等）弹窗确认；音频不上传云端；MCP 工具默认需确认 |
| 记忆 | 短期会话 + 跨会话偏好 + 任务历史，SQLite 多文件持久化 |
| UI 页面 | 主面板（聊天式对话、任务队列、转写、实时推理流）、工具管理、历史、设置 |

## 架构

```
desktop (托盘/热键/通知)
  └─ app-binary (Tauri invoke/emit 桥)
       └─ agent (LLM 编排/意图分类)
            └─ task (任务队列/并发调度)
                 └─ tools (MCP/Skills/内置工具)
                 └─ input (录音/音频)
                 └─ memory (SQLite 持久化)
```

## 开发阶段

| 阶段 | 内容 |
|---|---|
| M1 | 桌面壳 + UI 骨架（Tauri初始化、托盘、热键、SvelteKit页面） |
| M2 | 录音 + 转写闭环（CPAL录音、VAD、MCP STT调用） |
| M3 | Agent 核心（LLM路由、意图分类、任务状态机、内置工具） |
| M4 | 工具生态（Skills脚本引擎、MCP自动发现、高危确认弹窗） |
| M5 | 并发与打断（并行调度、补充上下文、取消/暂停/恢复、通知） |
| M6 | 记忆与稳定性（SQLite全量、偏好学习、历史回溯、开机自启） |

## 关键约束
- 音频仅本机处理，云端只收转写文本
- 不实现语音播报
- 键鼠/窗口不内置，通过 MCP 接入
- 全量工具调用链记录，可审计
- 敏感配置加密存储（keyring / AES）
