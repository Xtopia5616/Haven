# ADR 1394：将真实物理盘 ENOSPC 从本次发布 Gate 豁免

## 状态

已按用户明确要求采纳；仅调整当前 Windows 发布 Gate 的验收范围。

## 背景

ADR 0395 与 ADR 0404 保留了在 disposable Windows profile/VM 上耗尽物理卷的验收项，用于核对 Windows VFS 错误、会话错误提示和恢复操作。当前主机只有 C:/D: 用户卷，没有已挂载的可丢弃测试卷，也没有管理员提升。用户明确要求本次“不验收”该项并从 Gate 清除。

## 决定

- 将真实物理卷 ENOSPC 验收从当前 Windows 发布 Gate 的必验项中移除。此决定是范围豁免，不是测试通过，也不声称 Windows 物理卷已满时的 UI/恢复行为已被实测。
- 保留 ADR 0395/0404 的 `SQLITE_FULL` 故障注入、事务失败原子性、错误分类与恢复文案证据。这些证据覆盖 SQLite 的可复现故障路径，不等价于真实 Windows 卷耗尽。
- 不创建 VM/VHD，不填满宿主 C:/D: 盘。VM、VHD 和磁盘写满均不再是本次 Gate 的依赖。
- 路线图 §5.1 明确标记此豁免；Gate 仍须通过其余真实 UI、恢复/回滚和安装生命周期项目。

## 影响与验证

- 无代码、配置、数据库或安装产物变更。
- 本次未执行物理盘 ENOSPC；截至 2026-10-24，C: 约余 7.23 GiB、D: 约余 7.26 GiB。
- 保留现有 `SQLITE_FULL` 与 SQLite I/O 错误提示行为。未来如再次要求真实物理盘验收，应在新的发布范围中重新立项并提供隔离环境。

## 回滚

后续发布可通过新的 ADR 与路线图变更重新加入物理 ENOSPC 验收；不得把本次范围豁免反向表述为实测通过。
