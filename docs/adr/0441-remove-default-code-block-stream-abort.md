# ADR 0441：移除默认代码块流式中止规则

## 背景

生产 LLM Router 默认启用 `no_code_blocks` 流式规则。模型一旦开始输出带语言标记的代码块，当前回答就会被中止并重试；已经显示的内容随之被清除，重试文本也可能不同。代码块只是聊天文本，不会自行执行；工具执行仍由现有授权与安全边界控制。

## 决定

生产 Router 默认不安装代码块流式规则。保留通用 `StreamRule` 能力，供显式安装的规则使用；移除 `code_block_abort` 构造器及其专属测试。

## 影响与回滚

模型可以正常输出带语言标记的代码块，不再因该规则触发整段流重置。其它显式配置的流式规则、重试与工具授权语义不变。回滚时恢复 Router 默认规则即可；不涉及配置、数据库或 IPC 变更。

## 验证

Router 单元测试确认默认实例允许 fenced code 输出；LLM crate 测试覆盖其余通用流式规则行为。
