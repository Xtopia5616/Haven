# ADR 1443：在 Git 授权中绑定工作树与元数据

## 状态

本记录取代 ADR 1442 对工作区外仓库根目录的临时限制。

## 背景

Git 可能从仓库子目录启动；linked worktree 的 `.git` 文件和 `commondir` 还会指向工作树以外的元数据。只声明 cwd 会导致确认后进程策略无法访问实际仓库，或者在执行阶段发现额外权限不足。

## 决定

授权请求解析器提供当前会话工作区，并将 Git 资源发现委托给 Git owner，在请求创建前发现工作树根及 Git 元数据。普通仓库使用 `.git` 目录；文件形式的 `.git` 通过不跟随重解析点的目录能力读取，解析其 `gitdir` 和可选 `commondir`，指针长度限制为 8192 字节。cwd、工作树根、worktree 元数据和公共元数据在同一个授权请求中列为写资源。Git 可运行 hooks 和 filters，申请的目录范围也适用于其子进程。

执行前重新发现目录并逐一匹配 proof 绑定的写资源；Windows 目录句柄保持到子进程启动。MXC 策略同时验证所有元数据写根，显式拒绝仍生效；默认只读元数据只有在其具体写资源获得范围扩展证明后可写。拒绝、取消或证明失效均不启动进程。原有网络许可和进程树隔离保持不变。Windows Git 需要共享交互桌面才能在 MXC 中初始化；授权请求明确列出子进程桌面句柄资源，只有 proof 包含该资源才使用兼容模式。用户可见文案说明共享桌面及窗口访问，MXC 仍限制剪贴板和输入注入。

## 风险与替代方案

目录指针属于不可信输入，不能直接扩大权限；读取有界且拒绝重解析路径。目录发现和进程启动之间仍存在指针文件变化的竞态，MXC 必须限制实际进程权限在已授权根内；FullAccess 的宿主进程不具备该目录隔离。对于 MXC 不可表示的隔离和显式拒绝继续失败，不回退宿主执行。桌面访问枚举增加 `process_handles`；旧授权仍可读取，不需要重置。此项独立于桌面读取及截图授权。

## 职责复核

`security/execution.rs` 与 `builtin/git.rs` 已超过 800 行；本次保留执行许可及 Git 资源发现各自的 owner，新增规模主要来自安全回归测试。后续若继续扩充 Git 发现与授权，应将发现逻辑和测试按稳定接口拆分。

## 验证与回滚

测试覆盖普通与 linked worktree 资源、指针错误、授权请求的资源、批准后的多根策略、默认只读范围扩展、拒绝及取消；Windows 使用真实 Git linked worktree 和 MXC 运行 `status`，并覆盖 proof 中缺少桌面句柄资源时不启用兼容模式。回滚本变更恢复对 linked worktree 的拒绝；回滚到不认识 `process_handles` 的旧版本前，需从保存的权限配置中移除该资源授权。无需重置数据库。
