# ADR 1094：以 UTF-8 安全方式识别外部 URL scheme

## 状态

已接受（2026-10-13）

## 背景

`open_external` 用固定字节偏移切片检查 `http://` 与 `https://`。对有效 Unicode 路径，切片端点可能落在多字节字符中间并 panic，导致普通本地路径输入触发命令崩溃。

## 决定

- 直接在 UTF-8 字节序列上使用 ASCII scheme 前缀匹配；不构造可能落在非法字符边界的 `str` 切片。
- URL scheme 仍只接受大小写不敏感的 HTTP/HTTPS；未匹配的目标继续走本地路径校验。

## 影响

非 ASCII 文件路径始终进入既有路径校验，不会在分类阶段 panic；URL 分类语义不变。

## 验证

单元测试覆盖 Unicode 字符横跨旧 7/8 字节切片边界的路径，并保留 HTTP/HTTPS 前缀测试。

## 回滚

不得在未经 UTF-8 边界验证的情况下按字节偏移切割 `str`。
