# ADR 0088：工作区次级状态动效

## 背景

工作区一级 Tab 已有轻量入场动效，但筛选后的任务、会话和资源列表仍会直接增删；任务详情、设置分组、空/加载状态、右键菜单和可展开资源卡的状态变化也缺少即时的空间反馈。用户能看到结果，却不容易判断这是一次操作后的更新还是页面重新加载。

## 决定

- 在 `app.css` 建立三类一次性动效原语：内容面板入场、列表项入场、菜单入场；统一使用现有 motion token。
- 将原语用于任务/会话/工具资源列表、任务详情、记忆与设置分组、异步状态、设置未配置/未保存提示和右键菜单。
- 资源卡展开使用短暂的垂直 slide，保留卡片高度变化的方向感；不对静态正文或持续运行状态增加循环动画。
- `prefers-reduced-motion: reduce` 下禁用新增的 CSS 动画；资源卡展开同步完成，保留状态变化和可用性。

## 替代方案

- 只继续增加页面级切换动效：无法覆盖筛选、选中和异步状态变化，不采用。
- 给所有控件增加 hover/scale 或循环动画：噪声和运动负担更高，不采用。
- 用 Svelte `key` 重建整个工作区：会破坏 keep-alive 页面状态，不采用。

## 影响与回滚

本次只改变前端呈现，不改变路由、IPC、持久化或业务状态。回滚本提交即可移除次级动效，不需要删除或重置用户数据。
