# ADR 1344：将会话图片历史检索扩展为通用资产检索

## 背景

ADR 1343 增加了按需查找压缩前图片上下文的入口。Haven 的会话事件还会关联音频、视频、文档、文本文件、剪贴板文件等受管资产；只搜索图片会遗漏这些与用户任务相关的材料，也会让模型误以为该入口不能检索其他资产。

## 决定

- 将 `session.image_search` 替换为只读、幂等的 `session.asset_search`。它按当前 session 和活动 transcript lineage 搜索用户附件与工具结果中出现的规范 `asset-*` 身份，不按图片模态筛选。
- 继续按事件分组返回有界关联语境及资产 ID、媒体类型、推断模态和文件名；搜索可匹配语句、工具输入、文件名、媒体类型、ID，以及可用的文本表示。
- 对可用的文本表示建立有界索引，覆盖提取文本、转写、OCR、图片描述、文档页和表格数据。响应只带相关的有界片段，不含资产字节、主机路径或文件内容全文。
- 对图片、音频、视频、文档、文本及其他受管文件使用同一资产检索机制。读取与分析仍交给现有 `media`、`files`、`clipboard` 等能力 owner，根据资产类型选择 operation。
- 延续 ADR 1343 的回滚过滤、扫描/结果/引用上限和低信任处理。`session.asset_search` 用于定位候选；模型只在需要时按 `asset_id` 查询候选内容，不把全部关联资产注入 prompt。

## 替代方案

- 为每种媒体类型分别创建历史搜索工具：会重复相同的 lineage、边界和分页逻辑，拒绝。
- 每轮把所有历史资产全文或媒体字节重新注入 prompt：会增加上下文开销并重新暴露与本轮无关的材料，拒绝。
- 在 Session 工具中复制媒体、文件或剪贴板读取能力：会绕过现有资产授权与内容处理 owner，拒绝。

## 影响

Memory 的历史检索 DTO 与 API 改为描述通用资产；Tools 将模型 operation 改名为 `session.asset_search`，提示词说明所有相关类型。既有 `asset_id` 和 transcript 事件格式不变，无数据库 schema、配置或持久数据迁移，也无需重置用户数据。本 ADR 取代 ADR 1343 中“只检索图片”的范围与 operation 名称，保留其按需、有界检索设计。

## 验证

- Memory 测试覆盖图像描述、PDF 提取文本、音频转写、剪贴板文本文件、工具生成资产及回滚分支过滤。
- Tools 与 Agent 测试覆盖新 operation、schema、目录、授权元数据和按需资产查询提示。
- 跨 crate 检查运行 workspace `cargo check`、严格 Clippy、全量 Rust 测试和 Rust 格式检查。

## 回滚 / 重置

回滚代码提交即可移除通用检索入口；既有 transcript 事件和资产不变，无需迁移或重置数据。
