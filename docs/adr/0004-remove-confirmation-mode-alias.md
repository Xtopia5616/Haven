# ADR 0004：删除安全确认模式 `always` 配置别名

日期：2026-08-26  
状态：已采纳

## 背景

安全确认模式的正式枚举为 `ask`、`paranoid`、`autopilot`，但旧配置值 `always` 仍被静默解释为
`ask`，前端读取设置时也重复做了该转换。这掩盖了用户配置已过期的事实，并使安全配置的实际
语义无法仅从文件判断。

## 决定

删除 `ConfirmationMode::Ask` 的 serde alias 和前端 fallback。出现 `confirmation_mode = "always"`
的配置按既有配置加载策略备份为 `config.toml.*.bak` 并以安全默认配置启动；发布重置文档明确
说明可手动改为 `ask` 或完整重置。

## 替代方案

继续静默映射，或把 `always` 变为新的正式模式。前者保留无到期兼容层，后者会制造与现有
`ask` 含义重复的安全状态，均被拒绝。

## 影响、验证与回滚

旧配置不再无提示地沿用；默认值仍为 `ask`，不会放宽权限。单元测试验证 serde 拒绝该值且
加载器产生备份。该变更不涉及数据库或快照；回滚可恢复 alias，但不应同时保留两种行为。
