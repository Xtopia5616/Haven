# ADR 0099：工具卡统一显示单工具 token

## 背景

工具卡此前同时显示两种 token：同一 ReAct step 的 provider 响应总量只显示在第一张
工具卡上；每张工具卡另外显示自己的参数与结果 token 估算。并行调用时，第一张卡的
数字因此会被误解为该工具的 token，和其它卡片的单工具数字不一致。

## 决定

- 工具卡统一只显示该卡调用参数与返回结果的 token 估算。
- provider 返回的真实 token 总量只保留在会话级 token 统计中，不再挂到某一张工具卡。
- 删除工具卡接收 step 聚合用量的展示路径及其无调用的聚合辅助函数；不改变后端
  usage DTO、持久化数据或会话级计费统计。

## 替代方案

- 把 provider step 总量平均分配给各工具：无法反映真实 tokenizer 或共享上下文，
  会制造伪精确数据，拒绝。
- 把同一个 provider 总量重复显示在每张卡：会放大视觉上的工具成本，拒绝。
- 保留第一张卡显示总量：继续造成并行工具卡之间的语义不一致，拒绝。

## 影响

工具卡的 token 胶囊在单工具、串行工具和并行工具场景都表示单张卡的数据规模。
会话顶部的 token 统计仍表示 provider 真实累计用量；本次不需要数据或配置迁移。

## 验证

```text
corepack pnpm --dir ui run check
corepack pnpm --dir ui run test:run
```

## 回滚与重置

代码回滚即可恢复旧展示逻辑；本次不改变持久化数据或配置，不需要用户重置。
