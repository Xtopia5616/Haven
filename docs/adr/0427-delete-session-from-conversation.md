# ADR 0427：从对话页删除当前会话

- 状态：Accepted
- 日期：2026-10-02
- 关联：ADR 0358、0376

## 背景

当前会话只能从历史界面删除。用户在对话页查看当前会话时，需要离开对话工作区才能执行同一操作。

## 决定

1. 在对话标题栏的会话操作区增加「删除会话」图标按钮；无活动会话时隐藏。标题栏在窄屏会将操作区放到标题下方，因此横屏和竖屏都能直接访问。
2. 删除前显示确认对话框，明确提示会话及消息记录会被永久删除。请求期间禁用重复提交和关闭操作。
3. 确认后复用 `sessionHistoryCommands.ts` 的 `deleteSession`，与历史界面调用同一个 `delete_session` 命令。成功提示由当前页面显示；`session:deleted` 继续作为投影与本地会话状态清理的权威通知。
4. 不新增 IPC、事件、持久化字段或数据库迁移。

## 替代方案

- 让用户从会话切换菜单中删除会增加操作步骤，而且会把破坏性动作塞进会话导航菜单。
- 为聊天页增加独立删除命令会复制现有契约和后端生命周期处理，容易令两处行为漂移。

## 影响与重置

只增加对话页入口和确认交互，复用既有删除语义，无需重置数据库或配置。取消确认不会改变会话；确认后由后端删除，且不可撤销。

## 验证

`ui/src/lib/SessionHeader.test.ts` 覆盖按钮可见性、危险样式、点击回调和无活动会话时隐藏；`sessionHistoryCommands.test.ts` 已覆盖共享命令的 `delete_session` 转发。另需运行 UI 类型检查与测试。
