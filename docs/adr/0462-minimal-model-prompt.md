# ADR 0462：采用最小可用的模型提示词

## 状态

拟议（2026-10-04，待二次校准）。

## 背景

Haven 将稳定系统提示、动态能力索引、当前可用的工具 schema、主机快照、会话上下文和跨会话记忆一起发送给模型。原系统提示重复说明了工具 schema、异步工具、常见执行习惯和回复方式；运行时快照也重复列出已在能力索引出现的 Skill/MCP，并暴露模型不需要的内部预算。

## 决定

1. 稳定主提示只保留 Haven 的产品定位、对记忆和检索结果的信任边界，以及动态能力索引。模型可从当前 API schema 和操作说明获取工具参数与专用用法；一般澄清、检查、验证、通知、语言和回复习惯不再逐条规定。
2. 删除每轮注入的通用工具使用说明。工具目录、Skill/MCP loader 和每个操作的描述继续作为相应能力的权威说明。
3. 工具失败时才提供短建议：环境类失败提示检查相关前提，逻辑类失败提示修正具体问题；不要求保持原路线或延迟切换方案。自动重试预算耗尽时仍明确禁止重复相同调用。
4. 从模型可见 runtime snapshot 中删除重复的 Skill/MCP 数量和内部上下文预算。保留模型无法自行得知且会影响本地执行的日期、主机、路径、Shell、实时能力与权限摘要。
5. 保留专用任务提示中的解析契约和领域策略，包括记忆 JSON 字段、摘要结构、语音/OCR 的逐字输出，以及检索内容的数据边界。
6. 后续仅在具体执行问题可复现时增加对应提示，并尽量限定到相关能力或失败场景。
7. Haven 自己生成并发送给模型的指令、媒体围栏和附件占位说明统一使用英文。用户输入、文件内容、Skill/MCP 定义和工具结果属于数据，保留原文，不为统一提示语言而翻译。

## 替代方案

- 保留通用清单：拒绝。其内容与工具 schema、操作描述或模型的一般能力重复，并可能把建议变成不必要的固定流程。
- 删除所有提示：拒绝。模型仍需要 Haven 的动态能力索引、检索数据的信任边界，以及机器可解析的专用输出契约。
- 一次性重写各操作说明：拒绝。它们是工具发现和具体操作的权威说明，本次只删除跨所有操作重复的使用手册。

## 影响与验证

常规请求的稳定系统前缀更短；Skill/MCP 名单只通过能力索引出现，内部预算不再进入模型上下文。Haven 生成的媒体/附件说明也统一为英文。具体工具的行为继续由当前 API schema 与操作说明决定。失败提示保留分类信息，但表达为建议。

验证：Rust workspace 格式、check、严格 Clippy、全量测试，以及 UI check、测试和生产构建均通过；`git diff --check` 通过。提示词在实际模型交互中的效果仍待二次校准。

## 回滚

恢复原 `MAIN_SYSTEM_PROMPT`、`TOOL_USAGE_NOTES`、完整 runtime snapshot、分类失败提示和中文媒体围栏即可；无数据库、配置或用户数据迁移。
