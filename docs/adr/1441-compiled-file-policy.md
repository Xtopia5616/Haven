# ADR 1441：授权器编译文件策略快照

## 背景与决定

`SecurityConfig.resource_policy` 是配置权威来源。授权器在配置更新时将其全局文件边界编译成单个快照，并在同一锁内替换；变更比较使用该快照，使策略凭据及进程边界的失效逻辑与实际策略一致。进程隔离所需的 sandbox 模式从有效写入模式派生。生命周期 hook 和摘要复用同一有效模式。

保留既有语义：workspace 或 inherit 带写入根目录时按 roots 执行，空 roots 在绕过配置校验的内部输入中按 workspace 处理。配置层仍拒绝全局 inherit 和空 roots。路径能力在使用时重新打开，以便失效路径、重解析点及其他失败继续封闭处理。工具级限制、会话工作区和临时授权仍在每次授权时组合。

## 替代方案与影响

保留分散字段会继续重复模式反推和变更比较；直接缓存已打开的目录能力则可能改变路径替换和失效语义。本变更不改变持久配置或 IPC，不需要迁移或重置；回滚代码即可恢复旧实现。

## 验证

运行 haven-tools 的锁定编译、严格 Clippy 和测试，并覆盖模式归一化、无效根目录、授权凭据失效和工具级路径求交。Windows 进程隔离仍依赖现有平台测试。

engine.rs 已超过职责复核阈值，现有授权规则及同文件测试占主要篇幅；本次只收敛既有策略状态，后续按授权策略 owner 和测试边界拆分，不在此安全语义重构中同时搬迁。
