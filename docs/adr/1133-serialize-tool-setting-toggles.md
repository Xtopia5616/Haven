# ADR 1133：按资源串行化工具开关写入

## 背景

Skills、MCP servers 与内置工具的开关共享乐观更新逻辑，但同一资源的快速连续切换可以并发发出写命令。旧请求失败后若无条件恢复旧列表，会覆盖较新的用户意图，并让 UI 与后端最终状态分离。

## 决定

- ToolsView 按资源类别与名称维护开关写入状态，同一资源的更新按用户触发顺序串行执行，不同资源仍可并行。
- 失败回滚受 generation 保护；过期请求不得覆盖最新意图。最新请求失败时刷新后端权威列表；刷新也失败时恢复最近一次确认值。
- 页面卸载后不再应用异步写入的结果。

## 影响与验证

该规则只影响 UI 状态收敛，不改变 Tauri 命令、配置字段或后端写入语义。Skills 与 MCP deferred-promise 回归覆盖快速 `false → true` 且两次写入都失败的情况；验证 UI tests、Svelte check 与生产构建。

## 回滚

可恢复旧的乐观更新实现；回滚前应一并移除覆盖旧失败回滚与重复写入的回归测试。
