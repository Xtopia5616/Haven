# ADR 1388：区分工具拒绝与结果不确定时的 Agent 提示

## 状态

已实施 — 2026-10-24。

## 背景

Agent 将工具失败作为后续模型输入。确认被用户拒绝、确认超时、当前安全策略拦截，以及副作用结果不确定，是不同状态；统一写成“不要重试”会遮住下一步所需的用户决定，也可能让模型误把策略拦截理解成可自动重试。

## 决定

1. 用户拒绝确认时，明确询问用户下一步；如用户仍要执行，必须走新的确认请求。确认过期时明确该操作尚未执行，并先询问是否仍需要。
2. 安全策略拦截时明确该操作在执行前已被阻止。Agent 可解释边界并使用已授权能力，或询问用户是否要调整对应设置；实际调用仍由授权 owner 再次校验。
3. 操作结果没有已证明安全的重放路径时，先核对结果，再询问用户是否验证或再次执行。
4. 不改变 `ToolRetryability`、confirmation lifecycle、授权判定、执行门禁或副作用行为；拒绝、过期与权限失败仍是不可自动重试状态。

## 替代方案

- 对所有拒绝和失败统一提示“不要重试”：会把未执行、被策略阻止与结果不确定混为一谈，也没有说明用户如何授权新的尝试。
- 放宽结构化 retryability：拒绝；模型提示的澄清不能改变 Agent 的自动重试条件或安全门禁。

## 影响与兼容性

仅更新 Agent 内部给模型的失败观察文本与对应测试；不改变外部 IPC、durable event、数据库、配置或工具执行权限，无需迁移/重置。回滚时还原对应观察文案，保留结构化 retryability 与授权 gate。
