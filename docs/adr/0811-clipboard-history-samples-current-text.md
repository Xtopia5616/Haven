# ADR 0811：剪贴板历史查询采样当前文本

## 状态

已接受（2026-10-08）

## 背景

`clipboard.history` 维护的是进程内文本环形历史。虽然 Haven 自己的文本写入和文本读取会记录内容，但其它程序更新系统剪贴板后，若调用方没有先用 Haven 读取，历史可能仍为空。

## 决定

每次显式调用 `clipboard.history` 时，先尝试读取当前系统剪贴板文本，并在可读且非空时记录，再返回有界历史。读取失败不丢弃既有历史；不启动后台监听，也不把内容持久化。重复文本沿用现有规则移动到最新位置。

## 影响与取舍

- 用户查询历史时可以看到其它程序刚写入的当前文本。
- 查询时只能采样当前内容，不能恢复两次查询之间已被覆盖的系统剪贴板内容。
- 该能力不引入数据库迁移或重置要求；历史仍随进程退出而清空。

## 验证

- 使用注入的剪贴板 reader 覆盖可读文本被加入历史、读取失败保留既有历史。
- 在 Windows 上检查 `clipboard.history` 对真实剪贴板的采样行为。
