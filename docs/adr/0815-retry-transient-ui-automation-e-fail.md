# ADR 0815：有限重试瞬态 UI Automation E_FAIL

## 状态

已接受（2026-10-08）

## 背景

Windows UI Automation 在查询窗口元素树时偶发返回 `0x80004005`（`E_FAIL`）。对同一窗口稍后重试通常成功。当前实现仅允许一次自动重试，第二次瞬态失败仍直接返回工具错误。

## 决定

`window.ui_tree` 对 UI Automation `E_FAIL` 最多执行三次总尝试，重试间隔固定为 50ms。其它 HRESULT 和普通错误不重试；超出尝试次数后返回最后一次原始错误。

## 影响与取舍

- 在短暂提供程序/元素树不稳定时，`ui_tree` 更可能自动恢复；最坏新增约 100ms 等待。
- 不对所有 UIA 调用全局重试，也不把错误转为空树，避免隐藏真实失败或误导后续控件操作。

## 验证

- 单测验证两次 `E_FAIL` 后成功、三次失败后返回错误，以及非 `E_FAIL` 不触发重试。
- Windows 环境对动态桌面窗口执行 `window.ui_tree`。

## 回滚

纯进程内行为变化，无数据迁移。回滚只将 UIA `E_FAIL` 自动尝试数恢复为两次。
