# ADR 0456：零容量音频环形缓冲区为空缓冲

- 状态：Implemented
- 日期：2026-10-04
- 范围：`haven-input::RingBuffer::push`
- 关联：ADR 0015

## 背景

`RingBuffer` 是公开导出类型，`new(0)` 合法；但向零容量缓冲区 push 非空切片时，环绕索引会对容量取模并触发 panic。当前音频引擎会把配置中的零值归一化，因此生产默认路径不可达，但公开类型本身缺少安全边界。

## 决定

零容量表示禁用缓冲区；push 是 no-op，RMS 为 0，drain 返回空切片，clear 保持空状态。

## 影响

合法零容量构造不再能因 push 而 panic。非零容量的覆盖和读取语义不变；没有配置、存储或 wire 变更，无需重置。

## 验证

回归测试对零容量实例执行 push、读取状态、RMS、drain 和 clear，并确认均安全且为空。

## 回滚

删除 `push` 的零容量保护会恢复对 `new(0)` 实例的除零 panic。
