# ADR 1440：按完成的执行记录 Hook 诊断

## 背景

同一 Hook 事件可在不同会话并发执行。先前各次执行分别修改共享的最近结果、失败码和命令位置，交错时可能把不同执行的数据组合在一起，误导排障。

## 决定

累计计数继续独立更新；最近结果、失败码和命令位置在每次执行完成时一次性更新，表达最近完成的执行。首次完成前结果为空；进行中不清除上次完成结果。外部字段和执行、权限、取消规则不变。

## 替代方案

串行化事件会改变运行时延迟和行为；为每次执行保留历史会增加容量与隐私边界。两者均不采用。

## 影响与回滚

仅改变进程内诊断语义，不修改持久数据、配置或 IPC 字段，无需重置。回滚代码与本文档即可恢复旧行为，但会重新引入并发诊断混淆。

## 验证

`cargo fmt --all -- --check`、`cargo check --locked -p haven-tools`、`cargo clippy --locked -p haven-tools -- -D warnings` 通过；`cargo test --locked -p haven-tools --lib lifecycle_hooks::tests` 12 项通过，包括交错完成诊断和 Windows MXC 用例。
