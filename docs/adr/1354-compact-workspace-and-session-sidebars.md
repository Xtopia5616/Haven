# ADR 1354：默认压缩两级侧栏并支持会话栏调宽

## 状态

已采纳并实施。

## 背景

1280px 对话页的主导航与会话栏原先分别占 200px 和 272px。四个一级入口无需默认占用完整导航宽度，固定会话栏也限制了内容空间。

## 决定

- 从 600 CSS px 起，主导航默认使用 80px 图标加短文字布局，按钮可展开为原有 200px 完整导航；不再按 1200px 断点自动展开。
- 从 840 CSS px 起，会话栏默认 240px，可折叠至 48px，保留展开和新建入口；低于此断点继续使用现有会话标题区入口。
- `SessionSidebar` 独立拥有折叠与调宽交互，不把布局状态加入聊天路由业务。会话栏支持指针捕获拖动、取消及捕获丢失处理；键盘左右键每次调整 16px，Home/End 调至 200/360px 边界，双击恢复默认。
- 主导航状态由壳层持有，会话栏偏好由前端 sessionSidebarLayoutStore 持有；重新展开及跨工作区切换保留宽度与折叠状态，应用重启恢复默认。折叠切换后将焦点交还对应按钮。
- 不变更 IPC、数据库、后端配置或会话业务状态，无需重置持久数据。威胁面仅为本地布局交互，无新增文件、网络或权限入口。

## 替代方案

- 只降低自动展开断点：无法持续保障大窗口内容空间。
- 完全移除完整导航：会失去产品标识、入口提示与完整状态展示。
- 只折叠而不调宽：长标题和不同窗口宽度仍难以兼顾。

## 验证

- 新增主导航展开/收起测试，以及会话栏键盘边界、默认宽度恢复、焦点恢复、折叠后新建、指针调宽与捕获丢失测试。
- 前端类型检查通过，无错误和警告；生产构建通过。
- 首次完整前端测试在 Node.js 24.20.0 下为 1394 通过、6 失败；随后会话运行结束状态恢复也完成实现，并在固定的 Node.js 24.21.0、pnpm 12.12.1 下重新验证：`pnpm run check` 无错误或警告，`pnpm run test:run` 的 165 个文件、1408 项全部通过。
- 2026-10-22 集成复验中，`cargo test --workspace --locked`、`cargo clippy --workspace --locked -- -D warnings`、`cargo fmt --all -- --check` 也通过。
- 浏览器预览验证 1280×720 下主导航 80/200px、会话栏 240/48px 及聊天内容空间，并验证真实指针拖动、键盘最大宽度、600/840px 和 480px 窄窗布局及历史、设置页布局。

## 回滚

恢复壳层的自动展开断点和聊天页固定 272px 列宽，移除 SessionSidebar 及 SessionRail 折叠入口。没有持久数据需要迁移或清理。
