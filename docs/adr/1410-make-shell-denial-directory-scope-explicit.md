# ADR 1410：明确 Shell 拒绝重试的目录授权范围

## 状态

已实施。确认界面和 Agent 摘要都明确说明一次性批准覆盖整个列出的目录及其子项。2026-10-25 UI 测试（1517 项）、Agent 定向回归、Svelte 检查和 workspace Rust 测试通过。

## 背景

MXC 的结构化拒绝记录可能指向单个文件，而 Haven 的一次性重试扩展通过目录 capability 交给 MXC。读取/执行被拒绝时会申请该文件的父目录只读权限；写入被拒绝时会申请该父目录可写权限。因此，批准范围可能大于首轮被拒绝的文件。确认框此前只列出路径并称“扩展目录权限”，没有醒目说明子目录和其它文件也会包含在授权范围内。

## 决定

- 当 Shell 的资源边界确认包含本地路径时，确认框在资源列表旁突出显示：本次授权覆盖列出的整个目录及其子目录和文件，不限于首轮被拒绝的单个文件。
- 操作摘要分别说明读取/执行拒绝会扩展为父目录只读，写入拒绝会扩展为父目录可写，并继续提示批准后会重跑完整命令以及首轮可能已产生副作用。
- 确认仅作用于当前重试，不保存授权、不修改设置；网络、UI 和其它不支持的拒绝类别不因该确认获得权限。

## 替代方案

- 只在资源列表显示目录路径：拒绝，用户无法从路径本身确定授权会递归覆盖目录内容。
- 把临时拒绝扩展改为精确文件 ACL：当前 MXC ProcessContainer 接口以目录为授权根，无法表达该边界。
- 不再为单文件拒绝提供重试确认：拒绝，这会移除受控的一次性恢复路径；确认提示必须准确表达它的目录级范围。

## 影响与回滚

仅调整 Shell 重试确认的用户可见说明，不改变权限编译、MXC 根目录或授权生命周期。无配置、数据库、session event 或 IPC 变化，无需重置数据。回滚只需恢复确认文本；不得删掉“整个目录及子项”的范围告知而保留父目录扩展行为。

## 验证

- UI 回归验证确认只有包含本地路径的 Shell 边界扩展显示目录级警示。
- Agent 回归验证确认摘要说明读取/执行与写入拒绝映射到的父目录权限。
- Rust 与 UI 检查结果记录在本轮实现报告；权限执行行为继续由 ADR 1401、1404 的测试覆盖。
