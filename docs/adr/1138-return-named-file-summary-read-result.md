# ADR 1138：用具名结果表达文件摘要读取状态

## 背景

文件摘要读取 helper 通过五元组返回内容、实际行范围、文件大小和截断状态。调用方依赖位置索引理解各值；测试也必须用元组解构才能验证范围和字节数。

## 决定

- 将五元组改为 `SummaryFileRead`，字段分别表达内容、实际起止行、文件大小（bytes）和是否截断。
- 调用方按字段名访问；测试明确验证边界值与单位。
- 不合并不同元数据，也不改变摘要读取行为。

## 替代方案

- 保留位置型 tuple 并依赖注释：拒绝。字段语义在类型定义和消费者处不可见。
- 改为无名 JSON map：拒绝。它会丢失编译期字段检查。

## 影响与验证

这是 Tools 内部返回类型规范化，不改变工具输入输出、文件读取上限或 renderer 契约，不需要迁移或重置。验证覆盖具名字段、实际行范围、文件大小字节数和截断标志，并运行 Tools locked tests、Clippy 与格式检查。

## 回滚

将内部类型和消费者恢复为旧 tuple 即可；没有持久数据或运行时状态需要清理。
