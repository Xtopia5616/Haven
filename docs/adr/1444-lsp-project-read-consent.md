# ADR 1444：LSP 项目读取范围随授权绑定

## 背景与决定

LSP 服务器可读取整个活动项目。授权请求在实时目录和快照路径中均声明该项目的读取资源；默认文件范围不足时由现有授权流程展示范围并请求确认。文档读取使用证明派生的读取策略，MXC 仅在证明含项目读取资源且批准了范围扩展时加入该项目的只读根。显式拒绝仍优先，临时目录保持唯一写根。拒绝、取消或失效证明不会启动服务器。

## 风险与替代方案

仅扩展单个文档会遗漏服务器对项目其他文件的读取；仅放宽 MXC 而保留默认文档读取策略会使批准后的调用失败。项目内的显式拒绝路径继续由进程策略约束；不支持的隔离仍失败，不回退宿主执行。

## 验证与回滚

回归测试覆盖请求资源、确认后的读取根和默认只读隔离。回滚会恢复原有默认范围限制。本变更不修改持久化格式，无需重置。
