# ADR 0408：UI 统一动画方案

- 状态：已采纳
- 日期：2026-09-29

## 背景

UI 动画此前分散在 CSS 覆盖规则和组件运行时分支中，导致不同页面采用不同的动效策略。

## 决定

- UI 动画统一使用各组件定义的时长和效果，不提供环境相关的动画分支。
- 删除弹窗动画 profile helper、动画专用运行时检测分支，以及 CSS/HTML 中对应的动画覆盖规则。
- 相关动效设计见 [UI 规范 §3.4](../ui.md)。

## 替代方案

- 保留全局 CSS 动画覆盖：仍会形成多套动画表现，不符合本次统一方案。
- 为弹窗保留单独的运行时 profile：与其他组件的 CSS 动画规则并存，会继续分散动画策略。

## 影响

Haven UI 始终播放组件定义的动画。仅改变前端动效策略，不影响数据库、配置、IPC 或用户数据；此前分散的动效降级规则由本 ADR 统一取代。

## 验证

- 全仓搜索确认运行时代码不再包含动画专用环境检测分支。
- `git diff --check`。

## 回滚与重置

恢复相关 CSS/HTML 覆盖规则、组件时长选择逻辑和弹窗 profile helper 即可；无需重置数据。
