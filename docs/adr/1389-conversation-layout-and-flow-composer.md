# ADR 1389：对话界面分层与正常占位输入区

- 日期：2026-10-24
- 状态：已接受

## 背景

标题、工作目录、执行方式、统计及多个会话操作争抢页头横向空间；输入工具在生成状态下换行，浮动输入框依赖测量并给消息补偿留白，附件或多行输入会压住欢迎内容。配色继续使用现有语义 token。

## 决定

- `SessionHeader` 保留标题和新建／完成，目录、执行方式及删除会话通过共享 `MaterialCollapsible` 按需展开。设置摘要保留模式与目录名称；不更改目录、权限和会话生命周期回调。
- `Composer` 在会话列正常占位，消息区独立伸缩与滚动；删除 overlay clearance helper 及 CSS 变量。`chatViewController.observeLayout` 观察阅读区尺寸，在原本跟随时滚动，回看历史时保持位置。
- 模型入口放在输入工具左侧，附件／录音／发送或中断放在右侧，投递方式和待操作入口单独成行。欢迎示例增加分类，未配置模型提示优先呈现。消息表面减少描边和阴影。
- 断点继续依据 `conversation` 实际容器宽度；低高度窗口复用既有输入高度限制。

## 替代方案

仅压缩字体或按钮会削弱可读性；继续为浮层维护动态留白仍需同步两个几何区域。正常占位由浏览器统一计算剩余空间。

## 影响与风险

不改变 Tauri IPC、事件、持久化身份、发送／中断、确认或后台任务契约；无需数据库或配置重置。删除会话入口增加一次展开操作，但仍使用原有确认。页头展开会占用阅读高度，菜单允许溢出面板，避免裁切目录选项。已有超过 800 行的路由、Composer 与 ChatBubble 沿用既有编排／行为／渲染 owner，本轮仅调整其布局，不新增状态机或跨领域职责。

## 验证

前端类型检查、完整 Vitest 与生产构建。滚动测试覆盖阅读区 resize 时保持跟随和回看意图；组件测试覆盖设置展开、目录／模式切换和生命周期回调。使用临时组件预览验证空白、生成、暂停、错误、完成及多行草稿，在 320–2560 CSS px、599/600、839/840、1199/1200 断点与 960×480 低高度窗口检查布局、菜单和操作可达性。临时预览不连接真实后端且不纳入发布。真实录音设备、模型生成和附件读取沿用既有单元测试，本轮不发起真实任务。

## 回滚

回退本提交即可恢复原界面，无数据清理步骤。
