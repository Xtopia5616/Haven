# ADR 1372：完善 Lifecycle Hook 编写、复用与排错流程

日期：2026-10-23

## 背景

七个生命周期事件已有可靠执行边界，但临时停用必须删除命令，脚本启动参数、匹配行为和错误码需要自行查阅。编辑器保存失败会隐藏草稿；对 Svelte 代理直接 structuredClone 也可能让已成功持久化的保存显示失败。

## 决定与不变量

- Common `HookCommand` 增加 `enabled`，缺省为 true。用户级与项目级均在匹配、进程授权前过滤停用命令；停用不会中断进行中的事件。配置仍完整校验，停用命令仍占每事件 8 条限额，保留顺序和原有 fail-closed 规则。
- UI 提供脚本启动模板、复制、事件筛选、草稿启用计数与放弃改动。单条编辑归 `HookCommandEditor`，JSON 草稿交换归 `HookConfigTransfer`，路由设置组件保留加载/保存/信任编排。原 runner 约 800 行中测试占约四分之一，本次保留该稳定私有 owner，未扩大生产职责。
- 匹配预览只在本地计算，与 Rust 大小写敏感、仅 `*` 通配规则一致；无工具名事件仅接受空 matcher 或字面 `*`。所有运行权限判断仍归 Rust。
- JSON 导入最大 8 MiB，拒绝未知字段、事件、错误类型和越界值；只替换可撤销的用户级草稿，必须另行保存。目录信任不包含在导入/导出中。字段校验按 UTF-8 字节限制，不回显导入值或底层异常。
- 保存先截取非代理快照，仅将该快照标为已保存；错误时保留编辑器和输入。诊断用静态错误码提供建议，并区分 veto 失败和通知失败；不新增敏感日志或执行试跑入口。

## 替代方案与风险

全局暂停会难以定位单条命令，删除后恢复会丢失配置，因此采用逐条持久开关。直接执行“测试 Hook”会产生真实系统副作用，因此本轮采用无副作用的 matcher 预览和可阅读脚本示例。模板不安装解释器、不创建脚本、不授予项目目录信任。

导入可以包含可执行命令，必须显示草稿替换与保存生效语义；未知字段拒绝、容量上限、字面参数和后端安全网关共同限制该入口。导出包含路径与参数，界面提示分享前检查。继续保持 5 秒事件预算、64 KiB 输入输出和进程树清理。

## 验证

配置覆盖缺省开关、停用往返、停用仍需校验和类型拒绝；runner 覆盖用户/项目信任配置的停用不触发进程授权、热启用恢复失败关闭。UI 覆盖匹配规则/Unicode/边界值、非法导入不改草稿、保存失败后重试、快照与放弃恢复、模板与事件过滤、隐藏错误阻止保存以及诊断语义。运行 Rust workspace check、严格 Clippy、测试、格式化，UI 检查、测试、构建和 IPC 漂移检查。

## 兼容、重置与回滚

旧配置缺省启用，新增可选字段不改变数据库或 session event，无需数据迁移或重置。IPC 由 Rust registry 重新生成。回滚时撤销对应代码并从用户和项目 Hook 配置中移除 `enabled` 字段（旧版本严格拒绝未知字段）；按既有发布/重置流程处理配置备份，不需清空会话数据。
