# ADR 1442：Git 工作区外工作目录的授权绑定

## 背景

Git 已声明工作目录的写入资源，但执行阶段此前无条件要求目录位于会话工作区，导致资源扩展获批准后仍失败。

## 决定

Git 允许使用与当前执行证明绑定的写入目录；匹配使用无重解析点的目录能力和规范路径。工作区外的仓库搜索限制在获授权目录内，避免凭一个子目录的授权访问其父目录。MXC 仍通过证明编译写入范围、检查显式拒绝和元数据保护；未授权目录不放行。

本切片只支持工作区外的工作目录本身是普通 Git 仓库根目录的情况。工作目录位于仓库子目录、linked worktree 及其独立公共元数据的资源发现和确认仍待实现；不得因此扩大父目录或回退宿主进程。

## 风险与验证

批准后目录可能变化；沿用现有目录能力及进程启动边界检查，仍须后续对仓库身份与元数据变化做端到端竞态验收。测试覆盖证明中的写资源与其他路径、只读资源的区别，以及 MXC 编译的写入范围。拒绝和取消仍由既有授权器处理，尚需端到端 Git 测试。

## 影响与回滚

无持久数据、IPC 或配置格式变更，无需重置。可回滚本切片恢复工作区限制。
